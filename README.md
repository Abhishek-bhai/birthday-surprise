BIRTHDAY — PREMIUM MOBILE WEBSITE

1. Open index.html in a browser to preview.
2. To publish free with GitHub Pages:
   - Create a public repository.
   - Upload index.html to the repository root.
   - Open Settings > Pages.
   - Choose Deploy from a branch, branch main, folder /(root), Save.
   - After deployment, share the Pages link with Jaya.

Note: Google Fonts and the decorative photo backgrounds use external internet resources. The layout remains usable if they do not load.
